## 📋 Next Steps for Users

### On Windows:
1. Clone the repository
2. Run `setup_windows.bat`
3. Double-click `START_WEB_INTERFACE.bat`
4. Open browser to http://127.0.0.1:8080
5. Click "Start" to begin detection

1. Clone the repository
2. Run `./setup_rpi5.sh`
3. Configure `.env.rpi`
4. Run `python run_edge.py`
5. Access via web interface (if enabled)
